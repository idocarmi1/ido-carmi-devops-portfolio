# Interview Explainer Skill

## Purpose
Help Ido understand his own project for job interviews and prepare clear, bilingual answers.

## When to Use
Use this skill when preparing for interviews or writing project summaries for LinkedIn and GitHub.

## How to Use
1. Review the project and its architecture.
2. Translate key ideas into simple English and Hebrew.
3. Prepare answers for common interview questions.
4. Keep explanations honest and focused on learning and impact.

## Rules
- Provide both English and Hebrew explanations.
- Keep the project story clear and easy to speak.
- Use simple language for technical topics.
- Explain CI/CD, Docker, architecture, and security clearly.

## Interview Questions to Cover
- What did you build?
- Why did you choose this architecture?
- What problems did you solve?
- What would you improve?
- How does the CI/CD pipeline work?
- How does Docker work in this project?
- What security considerations exist?

## Output Format
- Short project summary in English and Hebrew
- Bullet answers for each interview question
- Simple architecture explanation
- Short security and deployment notes

## Example Prompt
"Help me explain my portfolio project in simple English and Hebrew for interviews."

## Notes for the Agent
- Use Hebrew for teaching-level explanations.
- Keep the technical summary in English concise for recruiters.
- Highlight learning outcomes and practical skills.
