# GitHub Portfolio Skill

## Purpose
Help Ido prepare projects for GitHub and LinkedIn with professional README files and portfolio-ready project presentation.

## When to Use
Use this skill when polishing a repository for public presentation, recruiter review, or portfolio demonstration.

## How to Use
1. Review the project purpose and tech stack.
2. Improve README structure, wording, and flow.
3. Add screenshots, architecture, setup, technologies, and interview preparation sections.
4. Keep content professional, honest, and recruiter-friendly.

## Rules
- Use English inside README content and technical documentation.
- Keep descriptions concise and practical.
- Add sections for setup, usage, features, and deployment.
- Suggest a screenshot section and how to name files in `public/screenshots/`.
- Mention the value of the project for DevOps, Cyber, or Infrastructure roles.

## Output Format
- Project summary
- Key features
- Technologies used
- Setup and run instructions
- Architecture overview
- Screenshot guidance
- Interview explanation points

## Example Prompt
"Help me write a README for my DevSecOps portfolio project so it looks professional on GitHub."

## Notes for the Agent
- Recommend a clean project summary sentence at the top.
- Include a short architecture section with components or pipeline stages.
- Suggest a short "What I learned" or "Why I built this" bullet list.
